## 🏗 সিস্টেম কীভাবে কাজ করে? (Architecture Overview)

প্রজেক্টটি **Event-Driven Plugin Architecture** অনুসরণ করে:

1. **ইঞ্জিন ইনিশিয়ালাইজেশন (`main.py`):** বট রান করার সময় `main.py` ফাইলটি `Pyrogram Client` চালু করে এবং এর বিল্ট-ইন প্লাগইন ম্যানেজারকে নির্দেশ দেয় `plugins/` ডিরেক্টরিটি স্ক্যান করতে।
2. **ডাইনামিক প্লাগইন লোডিং:** `plugins/` ফোল্ডারের ভেতর থাকা প্রতিটি `.py` ফাইলকে স্বয়ংক্রিয়ভাবে একটি স্বাধীন মডিউল হিসেবে ইমপোর্ট করা হয়।
3. **হ্যান্ডলার ম্যাপিং:** প্লাগইনের ভেতরের ফাংশনগুলোতে থাকা `@Client.on_message` হ্যান্ডলারগুলো স্বয়ংক্রিয়ভাবে টেলিগ্রামের ডিসপ্যাচারের সাথে রেজিস্টার হয়ে যায়।
4. **আইসোলেশন (Isolation):** কোনো একটি প্লাগইনে বাগ (Bug) বা কোড ক্র্যাশ থাকলেও অন্য প্লাগইন বা মূল বট কখনো বন্ধ হবে না।

## 🛠 নতুন প্লাগইন তৈরি করার নিয়ম (Plugin Development Guide)

নতুন কোনো ফিচার যোগ করার জন্য `main.py` খোলার কোনো প্রয়োজন নেই। 

১. `plugins/` ডিরেক্টরিতে একটি নতুন `.py` ফাইল তৈরি করুন (যেমন: `plugins/echo.py`)।  
২. নিচের বয়লারপ্লেট কোডটি ব্যবহার করুন:

```python
from pyrogram import Client, filters
from pyrogram.types import Message

# কমান্ড হ্যান্ডলার (যেমন: /echo দিলে কাজ করবে)
@Client.on_message(filters.command("echo"))
async def echo_handler(client: Client, message: Message):
    # টেক্সট থেকে কমান্ড বাদ দিয়ে শুধু আর্গুমেন্ট নেওয়া
    text = message.text.split(maxsplit=1)
    if len(text) > 1:
        await message.reply_text(f"📢 আপনি বলেছেন: {text[1]}")
    else:
        await message.reply_text("কিছু লিখে কমান্ড দিন! যেমন: `/echo Hello`")
```
৩. ফাইলটি সেভ করুন। বট রিস্টার্ট দিলে এটি নিজে থেকেই একটিভ হয়ে যাবে।

## 💻 লোকাল মেশিনে রান করার পদ্ধতি (Local Setup)

১. **রিপোজিটরি ক্লোন করুন:**
   ```bash
   git clone https://github.com/your-username/OmniCore-Bot.git
   cd OmniCore-Bot
   ```

২. **ভার্চুয়াল এনভায়রনমেন্ট তৈরি ও একটিভ করুন (ঐচ্ছিক কিন্তু উত্তম):**
   ```bash
   python -m venv venv
   source venv/bin/activate  # উইন্ডোজের জন্য: venv\Scripts\activate
   ```

৩. **ডিপেন্ডেন্সি ইন্সটল করুন:**
   ```bash
   pip install -r requirements.txt
   ```

৪. **বট রান করুন:**
   * উইন্ডোজ/লিনাক্স টার্মিনালে ভ্যারিয়েবল সেট করে অথবা `config.py`-তে ডেটা দিয়ে রান করুন:
   ```bash
   python main.py
   ```

## ☁️ Koyeb ক্লাউডে ডিপ্লয় করার পদ্ধতি (Production Deployment)

প্রজেক্টে আগে থেকেই প্রোডাকশন-রেডি `Dockerfile` দেওয়া আছে।

১. কোডটি আপনার **GitHub** একাউন্টে পুশ করুন।
2. **[Koyeb Console](https://app.koyeb.com/)**-এ লগইন করে **Create App**-এ ক্লিক করুন।
3. **GitHub** নির্বাচন করে আপনার রিপোজিটরিটি সিলেক্ট করুন।
4. **Builder** হিসেবে `Dockerfile` অটো-ডিটেক্ট হবে।
5. **Environment Variables** ট্যাবে নিচের ভ্যালুগুলো যোগ করুন:
   * `API_ID`
   * `API_HASH`
   * `BOT_TOKEN`
   * `OWNER_ID`
6. **Instance Type** হিসেবে `Nano` বা ফ্রি টিয়ার নির্বাচন করে **Deploy** দিন।
